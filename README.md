# Exercícios em C

Repositório criado para armazenar exercícios e práticas de programação em linguagem C, desenvolvidos ao longo dos estudos de Ciência da Computação.

## 📚 Sobre

Este repositório reúne exercícios de diferentes níveis de dificuldade, com o objetivo de praticar e consolidar conceitos fundamentais da linguagem C.

Os exercícios evoluem gradualmente, passando por problemas básicos até estruturas e lógica mais avançadas.

## 🧠 Conteúdos praticados

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores aritméticos e lógicos
- Estruturas condicionais (`if`, `else`, `switch`)
- Estruturas de repetição (`for`, `while`, `do while`)
- Vetores
- Matrizes
- Strings
- Funções
- Ponteiros
- `struct`
- Busca e ordenação
- Manipulação de arquivos
- Menus e sistemas interativos
- Lógica de programação
